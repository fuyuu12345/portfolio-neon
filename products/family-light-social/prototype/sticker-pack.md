# 家灯 · 最小贴纸包（Ins 手账风）

先做 **12 个** 就够撑起三屏。统一色系：腮红粉 / 雾蓝 / 豆沙绿 / 沙米色。

## 规格建议
- 格式：PNG（透明底）+ 关键线稿可另存 SVG
- 尺寸：1024px 边长内，导出 @2x / @3x
- 线宽：偏细、圆角、轻微手抖即可，不要太儿童卡通
- 命名：`sticker-01-washi-check.svg` 这类

## 绘制优先级
1. **01 胶带 + 03 相框 + 05 小灯**（立刻有手账感）
2. **07 虚线框 + 09 夹子 + 11 信封**（功能区成形）
3. 其余点缀

## 不要先做的
- 复杂人物立绘、过多动物 IP（容易幼稚，父母端违和）
- 一整页满贴（Ins 手账也要留白）

## 三屏最少用法
- **家**：小灯 + 胶带 + 便签 + 虚线外出框
- **动态**：相框 + 角贴 + 格子胶带
- **默契**：夹子 + 信封 + 「今日」标签 + 爱心
