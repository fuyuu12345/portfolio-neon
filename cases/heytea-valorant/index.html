01 · INSIGHT

玩家要掉落，不要贴皮

联名成败取决于是否进入「赛季心智」，而不只是出一杯印 Logo 的茶。

失败路径

  • KV + 杯身 Logo，缺少「为什么现在买」
  • 无稀有度 → 无可晒差异
  • 开箱时长不够，内容只能拍「我买了一杯」
  • 玩家判定：品牌借流量
IMG · 反例
失败杯示意

机会路径

  • 玩家熟悉：预告→预览→掉落→晒单
  • 喜茶有门店与杯身，适合「到店开箱」
  • 普通铺量、稀有催店、传说冲话题
  • B站/抖音需要可拍 15–60s 的物件剧情

受众 A 核心玩家

18–28，在意编号与稀有度，愿为「能晒」到店。

受众 B 观赛党

看比赛刷剪辑；被开箱种草后用「喜提掉落」入场。

受众 C 喜茶原客

本就到店；联名提供打卡理由，扩大破圈。

PHASE 01 · 蓄热 · T-14 → T-1

先让玩家「知道有掉落表」

目标：预约量与话题认知。不卖货催单，先泄露稀有度规则，把「传说要抽选、稀有要蹲店」讲清。

阶段 KPI

  • 小程序预约 UV / 传说抽选报名
  • B站预告片播放与完播
  • 微博话题阅读与互动
  • 抖音开箱钩子 A/B 胜出 1 版

用户心智

  • 知道：有三层掉落
  • 想要：传说要报名，稀有要记门店
  • 等待：掉落日倒计时
T-14 ~ T-10

掉落表首爆

  • B站预告片上线
  • 微博主话题开启
  • 品牌号发「掉落表」长图
T-9 ~ T-5

钩子测试

  • 抖音 2–3 版开箱脚本测试
  • 小红书种草预热笔记
  • 门店物料进店、人员培训
T-4 ~ T-2

预约加压

  • 小程序传说抽选截止提醒
  • UP/达人预告接力
  • 朋友圈种子素材就绪
T-1

开箱夜前夜

  • 全端倒计时统一视觉
  • 确认稀有首日配额
  • 客服 FAQ 上线

五端 · 预告期动作

  • 抖音：测钩子，不放大未验证素材
  • 小红书：规则图文、预约引导
  • 腾讯：搜一搜词包上线；小程序预约页

PHASE 02 · 爆发 · T0 → T+3

掉落日：开箱刷屏，到店兑现

目标：开箱声量 + 稀有售罄感 + 传说核销。五端同步，门店杯墙成为内容发生器。

阶段 KPI

  • 开箱视频播放 / 跟拍量
  • 稀有售罄时速（分城市）
  • 传说核销率（72h 内）
  • 特调杯量 vs 日常基线

风险预案

  • 黄牛：核销窗 + 会员限购
  • 排队舆情：余量透明播报
  • 素材翻车：只用预审模板
T0 上午

亮灯

  • 杯墙启用
  • 稀有开售
  • 全端「掉落已刷新」
T0 午后

开箱峰值

  • 达人/UP 集中发布
  • 视频号短直播
  • 余量播报
T0 晚间

传说开奖

  • 抽选结果推送
  • 核销指引
  • 微博热议承接
T+1~3

补货与核销

  • 稀有补货节奏
  • 传说到店高峰
  • 胜出素材放量

五端 · 掉落日动作

  • B站：开箱长视频 + 实时弹幕互动
  • 抖音：模板挑战冲顶；DOU+ 放大胜出版
  • 小红书：杯墙/探店笔记矩阵
  • 腾讯：朋友圈加压；小程序核销高峰保障
  • 微博：话题主持 + 售罄店实时转

PHASE 03 · 余热 · T+4 → T+14

编号图鉴：把声量沉淀成资产

目标：UGC 图鉴、内容回流广告、预埋下赛季。情绪从「抢」转向「晒与收藏」。

阶段 KPI

  • 杯墙打卡 / 编号晒单条数
  • 图鉴征集投稿量
  • UGC 回流广告 CPA
  • 下赛季预约意向（彩蛋页）

资产沉淀

  • 开箱胜出素材入库
  • 编号故事精选成片
  • 门店杯墙可常驻到档期结束
T+4 ~ T+7

图鉴征集

  • 发起编号图鉴
  • 精选转发
  • 传说故事访谈（示意）
T+8 ~ T+11

内容回流

  • 胜出 UGC 进信息流
  • 小红书合集
  • B站周更合集
T+12 ~ T+13

复盘

  • 稀有/传说数据复盘
  • 门店反馈回收
T+14

彩蛋

  • 「下赛季掉落」预告
  • 预约名单沉淀

五端 · 长尾动作

  • B站：图鉴合集 / 故事向中长视频
  • 抖音：长尾挑战曲复用，降制作成本
  • 小红书：搜索长尾占位、合集页
  • 腾讯：私域复购券（示意）、素材再投
  • 微博：复盘话题 + 彩蛋预告
