# 家灯 · 微信小程序

低负担家庭连接：安心灯、家庭动态、默契问题卡。

路径：`products/family-light-social/miniprogram`

---

## 5 分钟本地跑通

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. **导入项目** → 选本目录 `miniprogram`
3. AppID：可先用「测试号 / 游客」；要给朋友用需注册真实小程序
4. 编译后即可：创建家庭 → 填「关于我」→ 家 / 动态 / 默契

> 本地存储模式：数据在本机。模拟器里用「添加编译模式 + 清除缓存」可模拟第二用户，但仍是同一设备存储。

---

## 给朋友跨手机用（必须云开发）

微信小程序**没有自带跨用户共享存储**，朋友要在自己手机加入你的家庭码，需要开通云开发：

1. [注册小程序](https://mp.weixin.qq.com/) → 拿到正式 AppID  
2. 把 `project.config.json` 里的 `appid` 换成你的  
3. 开发者工具顶部：**云开发** → 开通 → 记下环境 ID（如 `jiadeng-xxxxx`）  
4. 云开发控制台 → 数据库 → 建集合 **`families`**（权限建议：所有用户可读写，或按需收紧）  
5. 打开 `utils/cloud.js`，填写：

```js
const CLOUD_ENV = 'jiadeng-xxxxx'
```

6. 重新编译 → 你创建家庭后，朋友用同一小程序 + 家庭码即可加入  
7. **上传代码** → 公众平台设**体验版**，把体验者微信号加进成员列表，发给朋友

## 正式 AppID + 看日活/月活/留存/地域（检查清单）

> 游客号 `touristappid`、本机 `preview.html` **不会产生** 日活等统计。必须正式 AppID + 真实微信用户打开。

### A. 换成正式小程序

- [ ] 在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序，完成主体认证（个人/企业均可，类目按「社交 / 工具」等选）
- [ ] 拿到 **AppID**，写入 `project.config.json` 的 `"appid"`（替换 `touristappid`）
- [ ] 用该 AppID 重新导入/打开项目，开发者工具能正常编译
- [ ] （可选但推荐）按上一节开通**云开发**，便于跨手机；统计不依赖云开发，但产品体验依赖

### B. 发版给真人用

- [ ] 开发者工具：**上传** 代码，填写版本号与备注（如 `0.1.0 首个体验`）
- [ ] 公众平台 → **管理 → 版本管理** → 选为**体验版**
- [ ] **管理 → 成员管理** → 添加体验者微信号
- [ ] 用手机微信打开体验版（扫码或小程序助手），完整走一遍：加入/建家 → 关于我 → 家 / 动态 / 默契
- [ ] 至少 2～3 个真实微信号各打开一次（自己 + 家人），第二天数据才像样

### C. 在哪里看指标

登录公众平台 → 左侧 **统计** / **数据分析**（名称随后台改版可能略有差异）：

| 指标 | 入口（常见路径） | 说明 |
|------|------------------|------|
| 日活 DAU | 概况 / 访问分析 | 当日独立访问用户 |
| 月活 MAU | 概况（切到月） | 当月独立访问用户 |
| 留存 | 留存分析 | 次日 / 7 日 / 30 日等 |
| 地域 | 用户画像 → 省份/城市 | 用户过少时可能为空或不展示 |
| 补充 | 访问页面、新增/回流、设备 | 看哪些页被打开、从哪来 |

- [ ] 发版后等 **次日（T+1）** 再查概况（当天数据常不完整）
- [ ] 确认看的是**正确的小程序账号**（别看错主体）
- [ ] 用户画像（地域等）需一定样本量；个位数用户时可能几乎空白——属正常

### D. 上架前别漏的配置（否则真机功能/审核会卡）

- [ ] **用户隐私保护指引**：勾选相册、摄像头（每日一更选图）；按实际再勾位置等（当前天气用城市名、不强制定位）
- [ ] **服务器域名**：request 合法域名加入  
  `https://geocoding-api.open-meteo.com`、`https://api.open-meteo.com`
- [ ] 正式对外再走：**提交审核 → 发布**；审核通过后统计面向全部访问用户

### E. 常见「为什么没有数据」

| 情况 | 原因 |
|------|------|
| 只有开发者工具预览 | 多数不计入或极少计入正式统计 |
| 仍是 touristappid | 没有公众平台统计后台 |
| 刚发体验版当天 | 等 T+1 |
| 只有你一个人打开 | 有打开次数，但留存/地域几乎看不出趋势 |
| 想看「发了多少动态」 | 那是自定义事件，不在本清单；需另做埋点 |

## 功能对照

| Tab | 内容 |
|-----|------|
| 家 | 今日日期/时间、家人居住地天气、状态灯、通话意愿、外出细节 |
| 动态 | 短文案 + 相册/拍照选图、轻反应 |
| 默契 | 子女发起；题按「关于我」匹配；先藏答案，家人答后揭晓 |
| 我的 | 家庭码、关于我、退出家庭 |

「关于我」可填现居住地；年龄互不可见。天气用 Open-Meteo（免 Key）。

真机天气需在公众平台配置 request 合法域名：
`https://geocoding-api.open-meteo.com`、`https://api.open-meteo.com`
（开发者工具可勾「不校验合法域名」先测）

每日一更选图：调用系统相册 / 相机。上架前在公众平台「用户隐私保护指引」中勾选  
「选中的照片或视频信息」「摄像头」，否则真机可能无法打开相册。
