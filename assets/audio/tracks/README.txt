酒吧 BGM 曲目目录（可像 VA-11 一样替换）

当前自带 3 首程序生成的氛围循环（WAV，可商用占位）：
- lorde-bar-1.wav  Neon Pad
- lorde-bar-2.wav  Alley Night
- lorde-bar-3.wav  Chill Bar

重新生成：node scripts/gen-bgm.js

换成你自己的歌：
1. 把 mp3/ogg/wav 放进本文件夹
2. 改 js/content.js → music.tracks 的 file / title
3. 刷新页面，点右上角 ♪ BGM 切换

建议：使用你有版权的音乐（如购买 VA-11 Hall-A 后提取 OST，或自有创作）。
